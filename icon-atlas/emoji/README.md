# Emoji и текстовые значки игры

72 значка из рабочей копии `master` распределены по трём атласам.
Маленький атлас подключён в игре через `src/ui/SmallIconText.jsx`.
Средний и крупный пока остаются исходниками для перерисовки.

| Атлас | Назначение | Значков | Ячейка | Размер листа |
| --- | --- | ---: | --- | --- |
| [small/atlas.png](small/atlas.png) | Управление, замки, стрелки, разделители | 26 | 32 × 32 | 256 × 128 |
| [medium/atlas.png](medium/atlas.png) | Валюты, ресурсы, статусы | 15 | 64 × 64 | 512 × 128 |
| [large/atlas.png](large/atlas.png) | Оружие, магия, персонажи, объекты | 31 | 128 × 128 | 1024 × 512 |

В каждой папке есть прозрачный `atlas.png`, lossless `atlas.webp` и
`atlas-numbered.png` с названиями. Обзор увеличивает ячейки до 128 px для удобства;
для перерисовки используй прозрачный лист без подписей.
Везде восемь столбцов, чтение слева направо, сверху вниз.

**[Правило распределения и добавления иконок → RULES.md](RULES.md)**

## Перерисовать атлас

Сохрани размер выбранного листа, прозрачность, порядок и границы квадратных ячеек.
Импортируй результат командой из корня проекта:

```powershell
python scripts/build-emoji-atlas.py --size small --import-atlas "путь/к/redrawn-small.png"
```

Для других листов укажи `--size medium` или `--size large`.
Импорт меняет только иконки выбранной группы; предыдущие PNG этой группы
сохраняются в `before-import/<группа>/` (копия перед последним импортом).
Не меняй каталог между экспортом и импортом перерисованного листа.

## Перерисовать одну иконку

В `icons/` лежат отдельные редактируемые PNG по 128 × 128. Например,
`gold.png`, `lock.png`, `arrow-right.png`. Эти исходники сохранены без потерь
при разделении. Экспорт масштабирует их до размера ячейки без сглаживания.
При импорте маленького листа ячейка увеличивается до 128 × 128 целыми пикселями.

После редактирования выполни:

```powershell
python scripts/build-emoji-atlas.py
```

Существующие PNG не перерисовываются из шрифта; генерируются только отсутствующие.
Пересборка также публикует маленький атлас в
`public/assets/ui/atlas/small-icons.png` и обновляет `src/config/smallIcons.json`.
Для публикации уже готовых листов отдельно: `node scripts/sync-small-icons.mjs`.

## Добавить иконку

Положи новый PNG под уникальным именем в `icons/` и укажи размер:

```powershell
python scripts/build-emoji-atlas.py --size small
```

`--size` назначает группу только новым пользовательским PNG. Без него они
попадают в `medium`. Новые emoji из исходников классифицируются по категории;
неизвестные — в `medium`, категорию и назначение следует уточнить вручную.

В `catalog.json` можно менять подписи и `sizeClass`. Для переноса в другую
группу одновременно установи `atlasSlot` в `null`: пересборка добавит иконку
в конец выбранного листа. Старое место останется свободным, остальные не сдвинутся.

## Реестры и источники

- `catalog.json` — редактируемый каталог: ID, название, категория, исходный PNG,
  `sizeClass` и постоянный `atlasSlot` внутри группы. Поле `slot` — прежний
  глобальный номер, сохранённый для идентификации; это уже не координата атласа.
- `manifest.json` — параметры трёх атласов, путь `image` и координаты каждой
  иконки, варианты Unicode и места использования в исходниках.
- `archive-v1/` — архив прежнего общего листа и его разметки. Не редактировать
  и не использовать для новых иконок.

Сканируются строки/JSX в `src/`, CSS `content`, `index.html` и старый реестр
emoji карточек. Символы из комментариев помечены `kind: comment`, из старого
реестра карточек — `kind: legacy-card`: они не обязательно видны сейчас в игре.
Варианты emoji объединены в одну иконку, составные символы не дробятся.
Удалённые из кода значки остаются в каталоге, чтобы сохранять разметку.

Для пересборки нужны Node.js с зависимостями проекта и Python с Pillow.
При создании отсутствующих PNG используются Windows Segoe UI Emoji / Symbol.
Сканер не читает Spine, звуки и другие тяжёлые игровые ассеты.
