# Перерисовка маленьких иконок

2026-09-18. 26 символов перерисованы одним атласом встроенным инструментом
`image_gen`. Референсы: прежний `small/atlas.png` и UI проекта `icon-atlas/ui-5x5.webp`.
Полный запрос сохранён в [prompt.txt](prompt.txt), исходный результат — `generated.png`.

Стиль: простой мрачный пиксельарт, холодное серебро и графит, угловатые формы,
минимальная детализация. Экспорт использует пять цветов:
`#141720`, `#343b4b`, `#687487`, `#b5bdcb`, `#e3e5df`.

`pack.cjs` выравнивает рисунки по ячейкам 32 × 32, сохраняет отступы минимум
4 px, масштабирует nearest-neighbor, приводит цвета к палитре без дизеринга
и альфа-канал к 0/255. `import.png` — готовый прозрачный лист 256 × 128;
`preview.png` — увеличение ×4 без сглаживания.

Для повторного импорта из корня проекта:

```powershell
node icon-atlas/emoji/small/redraw/pack.cjs
python scripts/build-emoji-atlas.py --size small --import-atlas icon-atlas/emoji/small/redraw/import.png
```

Рабочий атлас: `../atlas.png` и `../atlas.webp`. Обновлены также 26 PNG
в `../../icons/`; прежние изображения сохранены в `../../before-import/small/`.
Маленькие иконки подключены в `master` через `src/ui/SmallIconText.jsx`.
Средние и крупные иконки сохраняют прежнее оформление. Пересборка публикует
маленький PNG и его координаты для игры автоматически.
