# Нововведения — инструкция

Документация по всем механикам, добавленным в игру: система предметов, инвентарь, экипировка, сжигание в опыт, крафт, рарность/тинт иконок и балансные правки.

Всё реализовано в `src/App.jsx`. Иконки предметов лежат в `public/icons/`.

---

## 1. Предметы и рарность

### Рарности
Четыре уровня редкости (`RARITIES`):

| Рарность | Цвет | Тинт-оверлей |
|---|---|---|
| `COMMON` (Обычная) | серый | нет |
| `RARE` (Редкая) | синий `#0EA5E9` | синий |
| `EPIC` (Эпическая) | фиолетовый | фиолетовый `#a855f7` |
| `LEGENDARY` (Легендарная) | золотой | золотой `#f59e0b` |

### Фиксированная рарность шаблонов
Каждый шаблон предмета (`ITEM_TEMPLATES`) имеет **одну фиксированную базовую рарность**. Названия соответствуют реальным иконкам (`item_NN.png`). Распределение «пирамидой»:

- **COMMON — 11 шт.**: Инструменты палача, Запас зелий, Статуя горгульи, Зловещий кинжал, Ступка алхимика, Кожаная перчатка, Связка ключей, Проклятые монеты, Канделябр, Забытая шестерня, Свиток нетопыря
- **RARE — 7 шт.**: Астролябия, Кости предков, Букет аконита, Рунические камни, Фляга с ядом, Ржавые кандалы, Перо и чернила
- **EPIC — 5 шт.**: Древний гримуар, Череп ворона, Терновый венец, Рутиловый кристалл, Крылатый череп
- **LEGENDARY — 2 шт.**: Зеркало скорби, Проклятый гроб

Итого: больше всего обычных, меньше эпиков, мало легендарок.

### Тинт (перекраска иконки)
Чтобы расширить ассортимент, шаблон более низкой рарности можно «поднять» до целевой рарности — его иконка перекрашивается цветным оверлеем (`RARITY_TINT`), а к названию добавляется префикс (`Редкий…`, `Эпический…`, `Легендарный…`).

Логика подбора шаблона — `pickTemplateForRarity(rarity)`:
- «родные» шаблоны целевой рарности берутся **в 3 раза чаще** (без тинта, базовое имя);
- шаблоны ниже целевой рарности добавляются как перекрашенные варианты (`tinted: true`).

Рендер иконки с тинтом — компонент `ItemIcon` (используется в инвентаре, слотах экипировки, тултипе, анимации полёта и слотах крафта). Тинт накладывается через `mix-blend-mode: color` + `overlay`.

### Статы предмета
`generateItemOfRarity(rarity)`:
- **Главный стат** (`str` / `dex` / `int`, зависит от шаблона) — диапазон по рарности (`ITEM_STAT_RANGES`):
  - COMMON 4–7, RARE 9–14, EPIC 17–25, LEGENDARY 30–45
- **Вторичный стат** (`ITEM_SECONDARY`) — шанс появления и доля от главного:
  - COMMON: нет; RARE: 40% × 0.35; EPIC: 70% × 0.45; LEGENDARY: 100% × 0.55

Стат предмета прибавляется к персонажу через `getEffectivePlayer`, тултип формирует `formatItemStats`.

## 2. Выпадение лута

- При убийстве врага с шансом `LOOT_DROP_CHANCE = 0.65` падает предмет (`rollLootDrop`).
- Рарность выпавшего предмета определяется весами `ITEM_RARITY_WEIGHTS` = `{ COMMON: 68, RARE: 21, EPIC: 9, LEGENDARY: 2 }` (`rollItemRarity`).
- Предмет с анимацией летит в инвентарь (`FlyingItem`), в конце — белая вспышка на иконке.

---

## 3. Инвентарь

- Размер `INVENTORY_SIZE = 9`, отображается горизонтальной линией под карточками бойцов.
- Подложка инвентаря — горизонтальный градиент, уходящий в прозрачность по краям.
- **Переполнение → сжигание в опыт**: если инвентарь полон, при получении нового предмета **первый** предмет автоматически сгорает в XP (`ITEM_BURN_XP`: COMMON 4, RARE 8, EPIC 16, LEGENDARY 30), остальные сдвигаются (`addItemToInventory`).

---

## 4. Экипировка

- Под карточкой каждого бойца есть слот экипировки (с нахлёстом на карточку).
- Предмет надевается **перетаскиванием** из инвентаря в слот (drag-and-drop: `handleInvDragStart`, `handleEquipDrop`).
- Снятие — `handleUnequip`.
- При смерти бойца слот экипировки скрывается; после возрождения боец встаёт с **полным** HP (баг с возрождением на 0 HP исправлен в `resetGame`).
- Наведение на предмет показывает тултип (`ItemTooltip`) со статами; позиция тултипа ограничена краями экрана.

## 5. Крафт

- Кнопка «Крафт» — размером со слот, в линии инвентаря, по центру (`openCraft`).
- При открытии экран затемняется, по центру — **три слота** для предметов (`craftSlots`). Инвентарь дублируется внутри оверлея, чтобы из него можно было перетаскивать предметы поверх затемнения.
- Правило: **3 предмета одной рарности → 1 предмет следующей рарности** (`getNextRarity`, результат от `generateItemOfRarity(next)`, может быть и «родным», и перекрашенным).
- Предупреждения (`craftWarning`): если предметы разной рарности или их недостаточно — мелкий текст под кнопкой «Слияние».
- Закрытие — крестик (`closeCraft`); вернуть предмет из слота крафта — `removeFromCraft`.

## 6. Баланс

### Маг (p3)
Маг ваншотил и ломал баланс — его итоговый урон **урезан вдвое** (общий множитель `0.5` в `computeCardDamage` для `owner.id === 'p3'`). Это эквивалентно уменьшению всех его коэффициентов в 2 раза (базовый скейл `int`, `magicDmg`, сплэш-бонус). Воина и Разбойника не затрагивает.

### Сложность по секторам (рогалик)
Сложность задаётся **сектором**, а не уровнем игроков (автолевелинг по игроку отвергнут).

- В `spawnEnemies` множитель HP/наград по секторам стал **экспоненциальным**: `mult = 1.55^(сектор−1)` вместо линейного `1 + (сектор−1)·0.4`.
- По секторам примерно: с1 ×1.0, с2 ×1.55, с3 ×2.4, с4 ×3.7, с5 ×5.8 — растёт сопоставимо с экспоненциальным усилением отряда от слияния карт (`2^(уровень−1)`).
- Внутри сектора сложность также добавляется «лестницей» этажей: `s = этаж + (сектор−1)·6`.
- Логика рогалика: не дорос до сектора — проигрываешь и начинаешь заново, но **инвентарь и экипировка сохраняются** (`resetGame` их не сбрасывает при смерти).

> Базу `1.55` можно подкрутить, если сектора окажутся слишком резкими или слишком мягкими.

## 7. Справочник по ключевым символам

| Символ в `src/App.jsx` | Назначение |
|---|---|
| `ITEM_TEMPLATES` | Шаблоны предметов (имя, иконка, фокус-стат, базовая рарность) |
| `RARITY_TINT` | Цвета перекраски по рарности |
| `ItemIcon` | Рендер иконки предмета с тинт-оверлеем |
| `pickTemplateForRarity` | Подбор шаблона под целевую рарность (родной/тинт) |
| `generateItemOfRarity` / `generateRandomItem` | Генерация предмета |
| `rollItemRarity` / `rollLootDrop` | Розыгрыш рарности и дропа |
| `getEffectivePlayer` / `formatItemStats` | Применение и отображение статов предмета |
| `addItemToInventory` | Добавление в инвентарь + сжигание при переполнении |
| `getNextRarity` / `doCraft` | Крафт следующей рарности |
| `computeCardDamage` | Расчёт урона карты (включая нерф мага) |
| `spawnEnemies` | Спавн и масштабирование врагов по секторам |
