# VFX, графика и звук

Единый источник истины по презентационному слою: спрайты, боевые анимации, фоны/шейдеры, hover-обводка, эфемерные эффекты, UI-карточки, звук.
Боевая логика — в [`core.md`](./core.md), мета-экраны — в [`meta.md`](./meta.md).

---

## 1. Визуальный стиль

- **Тема:** тёмная (slate/near-black), акценты — янтарный, синий `#1E88E5` (герои/энергия), красный `#D32F2F` (враги), зелёный (разбойник), фиолетовый (маг).
- Пиксель-арт спрайты (`image-rendering: pixelated`), все растровые ассеты — **WebP**.

---

## 2. Спрайты и атласы

- Атласы 1280×1280, кадры 320×320 (4×4), idle 15–16 кадров, 7.5 fps. Рендер — `CharSprite` через `background-position`.
- Словари: `CHAR_ATLASES` (герои), `CHAR_ATTACK_ATLASES` (атака героев, 16 кадров, 14 fps), `ENEMY_ATLASES` (враги), размер `CHAR_SPRITE_SIZE`; перекраска героев — `charColorizeFilter` (`CHAR_COLORIZE`).
- **Анимация атаки героя**: играет при любом розыгрыше карты. Состояние **пер-геройное** (`attackAnims: { [heroId]: { play, phase, holdAtFrame, cycled } }` + `attackSeqActiveRef`), НЕ `animatingPlayerId` (он один на всех, параллельный розыгрыш его перетирает). `play` — счётчик перезапусков: каждое звено ритм-серии инкрементит его, `key` ремоунтит спрайт → **каждый удар мульти-атаки — своя анимация с 0-го кадра**. Спрайт играет один цикл (`once`) и замирает на последнем кадре; idle возвращается на границе цикла / при release. Idle — на `setInterval`, атака — rAF-циклом в игровом времени (`dt × qteSlowMo.scale`).
- **QTE-холд замаха** (ключевой инвариант): пока кольцо активно, замах играет в слоу-мо, доходит до **кадра перед ударом** (`holdAtFrame = impactFrame − 1`) и **ждёт вердикта** — анимация НЕ завершается сама. Вердикт: клик Perfect/Good (`mult > 1`) → фаза `fastFinish`, быстрый доигрыш до конца в реальном времени (×3); **miss** → фаза `finish`, холд снят, замах доигрывается сам в обычном темпе. Работает и для PRECISION-кольца, и для каждого звена RHYTHM-серии.
- **Тайминги от атласа атаки** (`impactFrame`, `frameCount/fps`): melee — импакт на кадре удара (воин 4-й ~286мс, рога 8-й ~571мс); **ranged/magic одиночный без кольца** — снаряд вылетает с задержкой `animMs − flightMs` и прилетает ровно к последнему кадру анимации, импакт = конец анимации; **ranged с кольцом** — снаряд привязан к вердикту: цепочка «клик → быстрый каст → вылет → полёт (`flightMs`) → импакт», пока холд — ничего не летит. Всё в игровом времени (`qteSlowMo.delay`).
- **Подсветка QTE-героя** (`qteHeroId` + `CHAR_QTE_GLOW`): пока герой отыгрывает своё кольцо (или весь ритм-стрим), его моделька светится собственным цветом (воин — синь, рога — лайм, маг — фиолет) и растёт ×1.1 через изинг с овершутом (`cubic-bezier(0.34,1.56,0.64,1)`). Гаснет на вердикте кольца / в конце серии. Watchdog, `safeAnim` и `resetGame` принудительно сбрасывают `attackAnims` и `qteHeroId`.
- **Все атласы в `PRELOAD_ASSETS`** — иначе враги «проявляются» с задержкой.
- Спрайты врагов **зеркалятся** через `scaleX(-1)` на внутреннем div; направление прыжка считается в **неотзеркаленной** системе координат на внешнем div.
- **Формации** (`CHAR_FORMATION` / зеркальная `ENEMY_FORMATIONS`): Воин — по центру, шаг вперёд; Разбойник — сверху-слева; Маг — снизу-слева. Враги зеркалят позиции. Босс крупнее (×1.5625) со сдвигом позиции.

## 3. Боевые анимации

- **Melee-прыжок:** вектор до цели из `getBoundingClientRect`, через двойной `requestAnimationFrame`, transition атаки ~300 мс (совпадает с моментом урона), возврат ~600 мс.
- **Ranged/AoE:** атакующий не двигается, летит только снаряд через `vfxList` (`CombatVfx`). Стрелок — стрела (`vfxType: 'arrow'`).
- **HP-бар врага** (`EnemyHpBar`): узкий прямоугольный, без цифр, скрыт по умолчанию, всплывает при уроне и гаснет через ~1с. Двухслойный: белый «откушенный» кусок мгновенно показывает прежнее HP, затем сужается.
- **Предсмертный вид** (`lowHpPulse`): при HP < 30% спрайт пульсирует тускло-тёмно-красным CSS-фильтром (~#641212).
- **Прочее:** всплывающие числа урона (крит крупнее/«CRIT!»), частицы крови, тряска экрана (`triggerImpact`, интенсивность от урона), белая вспышка при ударе, подсветка целей (`flashingTargets`), карточки с tilt/parallax-бликом (`TiltWrapper`).
- Комбо-тиры масштабируют VFX: `COMBO_VFX_SCALE`, `COMBO_VFX_PARTICLE_COUNT`, `COMBO_BLOOD_COUNT`.

### Защита анимационных колбэков (не ломать!)

Исключение в `setTimeout`-колбэке атаки замораживало героя у врага (был кейс с `ReferenceError`, фикс `975c1f4`). Два уровня защиты:
1. **`safeAnim(cb)`** — обёртка боевых колбэков: ловит исключение, сбрасывает все анимационные флаги (`isAnimating`, `animatingPlayerId/EnemyId/TargetIds`, транслейты, `vfxList`).
2. **Watchdog** — если `isAnimating` висит дольше `COMBAT_ANIM_TIMEOUT_MS` (3с), бой принудительно размораживается с `console.warn`.

Правила: любой боевой `setTimeout`-колбэк — только через `safeAnim`; константы, читаемые в асинхронных цепочках, не удалять/переименовывать без полного grep.

## 4. Эфемерные эффекты (`FxLayer`)

Попапы урона, частицы крови, летящие карты/XP/предметы, штампы мод-карт живут в собственном компоненте с **императивным API через `fxRef`** (`spawnDamagePopup(s)`, `spawnBlood`, `spawnFlyingCard/Xp/Item`, `spawnModStamp`, `clearAll`). Их частые обновления **не перерисовывают** `App` — не переносить их обратно в стейт `App`.

## 5. Индикация комбо и QTE-визуал

- **`ComboIndicator`** (справа от арены): две руны (`combo_rune_inner/outer.webp`) вращаются независимо в разные стороны, в центре — номер карты в цепочке. Появляется только если у разыгрываемой карты есть потенциальные звенья продолжения.
- **Подсветка карт**: только последующие (потенциальные) звенья активной цепочки — бейдж `COMBO +50%/+150%`, число урона желтеет, золотое свечение плашки. Первое звено не подсвечивается.
- **QTE-кольцо** (`QteOverlay.jsx`, v2): виньетка-фокус (radial-gradient по координатам цели), крупная карта-контекст (иконка 72px + имя), пульсирующая мишень, пояса зон GOOD/PERFECT, белое кольцо с ease-in-quad (rAF пишет `transform` напрямую в DOM, без setState на кадр), янтарный «заряд» в good-окне. Вердикт — ударная волна `qteShockwave` + 8 искр `qteSpark` (perfect) + текст `qtePop` 42px. AoE-вариант укрупнён ×1.35. Механика и изинги — в [`core.md`](./core.md), раздел 4.
- **Bullet-time под QTE** (`qteTimeScale.js`): пока кольцо активно, все Web Animations документа (прыжки, снаряды, idle-атласы, попапы) плавно замедляются до `playbackRate 0.35` единым rAF-циклом; узел `[data-qte-overlay]` исключён — кольцо в реальном времени. WebGL-фон (`ShaderBackground`) живёт на своём rAF и не замедляется — осознанно (это фон, а не действие).

## 6. Фоны

- **`ShaderBackground`** — полноэкранный WebGL fragment-шейдер (FBM-небула), цвет зависит от сектора (синий → с глубиной красный). 3 тира качества с авто-деградацией: `[scale 0.6, 30fps] → [0.45, 24fps] → [0.3, 20fps]`. На `document.hidden` rAF замораживается; на программном рендерере (SwiftShader/llvmpipe) сразу худший тир.
- **`ImageBackground`** — ЧБ пиксель-арт локации (`BG_LOCATION_SETS`, `bg/locations/*.webp`), красится цветным оверлеем через `mix-blend-mode: color`.
- На экране подготовки и оверлее раскрытия карты глобальные фоны/блюр **отключаются** ради производительности.

## 7. Hover-обводка (Таверна)

- **`ShaderOutlineWrapper.jsx`** — обводка по силуэту при наведении: WebGPU-пасс для статичных `<img>`, CSS drop-shadow fallback для атласных анимаций / без WebGPU / пока шейдер не готов. Хитбокс — декларативный `%`-прямоугольник (единственная кликабельная зона обёртки), hover-scale ×1.04.
- **`gpu/alphaOutlinePipeline.js`** — WGSL-шейдер: alpha-based outline, **outline-only pass** — канва отдаёт только «хвост» контура под DOM-`<img>` (нет шва на антиалиасном крае, исходник остаётся в DOM). Uniform-код и layout задокументированы в файле. API: `createAlphaOutlineRenderer(canvas)` → `{ uploadTexture, render, destroy }` или `null` без WebGPU.

## 8. UI-карточка способности (`AbilityCard`)

Сверху вниз: название + кружок маны → иконка → плашка редкости → строка «Наносит N урона по <цели>» (число окрашено через `getCardStatColor`: magic — синий, ranged — зелёный, melee — красный) → строка вторичного эффекта → строка цели.

Подсветка: комбо — жёлтым (см. раздел 5); активный бонус «Усиление цепи» подсвечивает урон янтарным.

## 9. Звук

- **Фоновый трек:** `public/file.mp3` — фоновый `fetch`-стрим, **обрезается на первой половине** (поиск корректного MP3-фрейма по байтам `0xff 0xe?`), декодируется в Blob URL. Громкость по умолчанию 0.35 (`musicVolume`).
- **SFX:** пре-генерированные `.wav` в `public/assets/sfx/` (ui/combat/game/map/events). Генератор — `scripts/gen-sfx.mjs` (jsfxr, запуск вручную при изменении пресетов). В рантайме — `Audio` с кэшем (`playSound`), громкость `_sfxVolume` (модульная переменная из стейта `sfxVolume`).
- **Маппинг VFX → звук удара** (`getCombatHitSound`): магические (`fireball/ice_spike/lightning/dark_void/magic_spark`) → `hit_magic`; `smash` → `hit_heavy`; `poison` → `hit_poison`; остальные → `hit_light`.
- **QTE:** perfect → `hit_heavy`, good → `click`, miss — без звука.

---

## 10. Прелоадер

`Preloader` + `PRELOAD_ASSETS`: прогрев wav-звуков, атласов героев/врагов, `corner.webp` до старта. Кнопка «Войти» стартует музыку (обход autoplay-политики). Отдельный индикатор «Загрузка медиа» (`mediaBytes`) — фоновая догрузка тяжёлых медиа после входа.
