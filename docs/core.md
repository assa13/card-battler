# Кор: боевая система

Единый источник истины по боевому ядру: герои, карты, урон, комбо, QTE, дебаффы, враги, фазы боя.
Дизайн и реализация — вместе, по доменам. Обзор игры — в [`../GDD.md`](../GDD.md), структура кода — в [`../instructions.md`](../instructions.md).

---

## 1. Герои (отряд игрока)

Отряд всегда состоит из трёх фиксированных героев. Они не выбираются и не меняются.

| ID | Имя | Иконка | Базовый HP (`baseMaxHp`) | Тип урона карт | Цвет темы |
|----|-----|--------|------|-----|-----|
| p1 | Воин | 🛡️ | 50 | физический (melee) | синий (`bg-blue-900`, акцент `#3b82f6`) |
| p2 | Разбойник | 🗡️ | 35 | физический (ranged) | зелёный (`bg-green-900`, акцент `#22c55e`) |
| p3 | Маг | 🔮 | 25 | магический (magic) | фиолетовый (`bg-purple-900`, акцент `#a855f7`) |

### 1.1. Боевые модификаторы (вместо характеристик)

**Базовых характеристик (сила/ловкость/интеллект) в игре НЕТ.** Урон и способности от них не зависят. Идентичность героя задаётся его картами (тип урона + множитель) и набором надетых предметов.

У каждого героя есть три боевых модификатора, по умолчанию все = **0**, источник — **только предметы** (и усиление «Эликсир Мощи»):
- **`atk` (Атака)** — +% к **физическому** урону карт (melee/ranged).
- **`matk` (Маг. атака)** — +% к **магическому** урону карт (magic).
- **`crit` (Крит)** — +% к шансу критического удара (кап 75%).

### 1.2. Максимальное HP

`maxHP = baseMaxHp + (hp-бонус надетого предмета)`. Источники роста `baseMaxHp`:
- **уровень отряда:** при level-up каждый герой получает `HP_PER_LEVEL` (Воин +8 / Разбойник +6 / Маг +4) к `baseMaxHp`;
- **событие «Семя Жизни»:** +50% к `baseMaxHp`;
- **предмет** с бонусом `hp` (только пока надет).

При надевании/снятии предмета `maxHP` пересчитывается; если текущее HP больше нового максимума — обрезается.

### 1.3. Броня (`armor`)

Отдельный показатель, по умолчанию 0. Повышается **мод-картой «Закал брони»** (раздел 2.4). Снижает входящий урон врага: `получено = max(1, урон_врага − armor)`; при поглощении броня уменьшается (`applyIncomingDamage`).

**Длительность:** только в рамках **текущего раунда** (ход игрока → ответ врагов). Обнуляется при **новой раздаче** карт и в начале **нового боя**. Между раундами одного боя не переносится.

## 2. Карты способностей

Каждая боевая карта принадлежит конкретному герою (`ownerId`) и может быть разыграна только им. Существуют также **мод-карты** — универсальные (раздел 2.4).

### 2.1. Параметры карты

- **name** — название; **cost** — стоимость в мане; **icon** — emoji.
- **mult** — базовый множитель урона.
- **dmgType** — тип урона: `melee` / `ranged` / `magic` (определяет, какой модификатор предметов усиливает карту: `atk` или `matk`, и цвет урона в тексте).
- **targeting** — выбор целей (раздел 2.1.1). По умолчанию у большинства карт — `all`.
- **secondary** — вторичный эффект-дебафф (раздел 5), у некоторых карт.
- **rarity** — COMMON / RARE / EPIC / LEGENDARY (оформление; влияет на скорость QTE).
- **vfxType** — тип визуального эффекта и звука удара.
- **level** — уровень карты (старт 1), растёт выбором улучшения на level-up (×2 урона за уровень).

#### 2.1.1. Цели атаки (`targeting`)

Три режима. **~67%** карт бьют по всем (`all`), **~20%** — по 2 случайным (`random2`), **~13%** — по одному сильнейшему (`strongest`, по `maxHp`, затем по текущему HP). Комбо **не меняет** тип цели.

| Значение | Поведение |
|---|---|
| `all` | Все живые враги (дефолт) |
| `random2` | 2 случайных живых врага (если враг один — бьёт его) |
| `strongest` | Один враг с наибольшим `maxHp` |

Реализация: `getCardTargeting(card)` → логика в `App.getTargets`; для `random2` при наведении используется стабильный превью-сид, при розыгрыше — настоящий рандом (`pickRandomAliveIndices`).

### 2.2. Полный список боевых карт по героям

У каждого героя — **чёткий механический архетип**, без пересечений между классами:
- **Воин — «Джаггернаут»:** тяжёлые удары, CC (стан/уязвимость), скейл от брони; мульти-удар на стартовой карте и Берсерке.
- **Разбойник — «Тысяча порезов»:** дешёвые карты 0–1 маны, мульти-цели (`random2`/`all`), стак кровотечения; естественные стартеры и мостики комбо. Больше всех мульти-ударов (3/5).
- **Маг — «Катализатор»:** дорогие нюки 2–3 маны, расстановка/детонация 🎯 Метки, спред дебаффов. Мульти-удар только на Цепной молнии.

> **Мульти-удар (`random2`)** = последовательная серия ударов с ритм-стримом QTE по каждой цели (раздел 4); у melee-карт (Удар мечом, Берсерк) — с пинбол-рывками героя между целями. Распределение по коллекции: Воин 2/5, Разбойник 3/5, Маг 1/5. **Исключение — Кинжал (cost 0): жёсткий бан QTE**, бьёт 2 цели одновременно без стрима.

### 2.3. Колода, слоты и старт

- **`CARD_POOL_SIZE = 4`** — у каждого героя 4 слота под карты: **1 заполнен с самого старта** (стартовая карта = базовая атака как полноценная карта колоды), **3 свободны**.
- **Стартовая колода — 5 реальных карт**, без «пустышек»/балласта: по стартовой карте на героя (3) + **2 универсальные мод-карты** (🛡️ Закал брони, 🔗 Усиление цепи) в общей колоде (`createInitialDeck`).
- Новые карты приходят на level-up и из события «Древний Фолиант» (`buildLevelUpOptions`, `kind:'new'`), апгрейды — `upgradeCardById` (+1 уровень). Когда все 4 слота героя заняты — только апгрейды.
- **Слияния карт НЕТ.** Прогресс силы карты — только апгрейд уровня (×2 урона за уровень).
- `purgeHeroFromDeck(heroId)` — карты погибшего героя удаляются из руки/резерва/сброса.

### 2.4. Мод-карты (универсальные)

Не привязаны к классу и **не занимают персональные слоты героев**. Безхозные (без `ownerId`), попадают в **общую колоду**: приходят в руку любому герою по очереди раздачи. Дедупятся глобально (по одной каждого типа на отряд), апгрейдятся по уровню (значение ×уровень). Выдаются с самого старта игры.

| Карта | Cost | Эффект (база, ×уровень) | Длительность |
|---|---|---|---|
| 🛡️ Закал брони | 0 | +8 к `armor` героя | до конца **раунда** (сброс при новой раздаче) |
| 🔗 Усиление цепи | 1 | +12 к урону **следующей** атакующей карты | только **текущий ход игрока** (сгорает при завершении хода) |

Мод-карты не наносят урон и не выбирают цель. **Их эффект скейлится в комбо** тем же множителем, что и урон (2-я карта ×1.5, 3-я+ ×2.5). Код: `MOD_CARDS`, `MOD_CARD_LIST`, `isModCard`, `getModValue`, ветка `playModCard`. QTE мод-карты **не триггерят**.

## 3. Расчёт урона

### 3.1. Единая формула (`computeCardDamage`)

```js
base   = card.mult * CARD_BASE_POWER(=7.5, нерф ×0.5) * 2^(level − 1)
atkPct = card.dmgType === 'magic' ? owner.matk : owner.atk   // %, с предметов
total  = base * (1 + atkPct/100) * bonus                     // bonus = combo ×1/1.5/2.5
damage = max(1, round(total))
critChance = min(0.75, owner.crit/100)
```

Порядок модификаторов при розыгрыше (`playCard`):
1. `computeCardDamage` → базовый урон с комбо-множителем.
2. `+ chainAttackBonus` («Усиление цепи», плоско, тратится на одну карту).
3. `× QTE-множитель` (×1.35 / ×1.15 / ×1.0 — раздел 4).
4. Пер-цельные модификаторы: крит (×2), 🎯 Метка (гарант. крит + `×mark.mult`), 🛡️ Пробитие (`×(1+vuln)`).

- `rollCardDamage` катит случайный крит; `computePreviewDamageOnEnemy` — та же база **без** случайного крита, но **с** Меткой/Пробитием цели (используется для превью при наведении и проверки летальности QTE).
- Нерфа мага ×0.5 **нет** — баланс задаётся `mult` карт.

### 3.2. Комбо (цепочка)

- Состояние: `lastPlayedCost`, `comboStreak`. Цепочка **продолжается**, если `card.cost === lastPlayedCost + 1` подряд в одном ходу. Разрыв сбрасывает шаг; начало хода сбрасывает всё.
- Множители по шагу — `COMBO_DAMAGE_MULT = [1, 1.5, 2.5]` (UI: `+0% / +50% / +150%`): 1-я карта ×1.0, 2-я ×1.5, 3-я+ ×2.5.
- Тот же коэффициент множит **силу вторичных эффектов** (`comboEffectMult` → `buildSecondaryPayload`).
- Комбо **не меняет** `targeting`.

### 3.3. Крит

- Шанс = `min(0.75, crit/100)`, только с предметов. При крите урон ×2.
- 🎯 Метка **гарантирует** крит и ещё домножает урон (раздел 5).

## 4. QTE «Точный удар» (Perfect Hit)

Скилл-чек на тайминг: при розыгрыше значимой карты поверх цели появляется сужающееся кольцо; точный клик усиливает удар. Компонент — `src/QteOverlay.jsx`, интеграция — `playCard` в `App.jsx`.

**ЖЁСТКИЙ БАН: карты за 0 маны (Кинжал) НИКОГДА не триггерят QTE** — ни одиночный, ни стрим; перекрывает все правила ниже (комбо, редкость, босса, летальность). Спам-карта не должна дёргать слоу-мо каждый розыгрыш.

**Триггер** (`shouldTriggerQte`) — НЕ каждый удар (только для одиночных/AoE-атак; ритм-стрим мульти-удара НЕ гейтится, см. ниже); `cost > 0` И хотя бы одно из:
1. Карта — 2-е или далее звено активной цепочки комбо.
2. Редкость EPIC или LEGENDARY.
3. Среди целей есть босс (`isBoss`).
4. Хотя бы на одной цели висит 🎯 Метка.
5. Ожидаемый урон летален хотя бы для одной цели (`computePreviewDamageOnEnemy(...).isLethal`, без случайного крита).

Одновременно активен максимум **один** QTE (`qteActiveRef`): параллельно разыгранная карта проходит без QTE (×1.0). Для последовательной серии (ниже) гвард захватывается на весь стрим.

**Два режима** (`isSequentialStrike` в `playCard`):
- **Одновременный AoE** (`targeting: 'all'`, >1 живой цели): один большой QTE в центре зоны врагов (`enemyZoneRef`), увеличен ×1.35. Один резолв — множитель применяется к урону всех целей разом.
- **Последовательная серия / ритм-стрим** (`random2` и будущие цепные атаки, 2+ живые цели): локальный QTE **над каждой целью по очереди**. Стрим — идентичность мульти-ударной карты, поэтому **играет при каждом розыгрыше** (НЕ гейтится `shouldTriggerQte` — иначе random2 неотличим от обычного удара); условия — `cost > 0` (жёсткий бан) и нет другого активного QTE. Асинхронный цикл (`for...of` + `await`): [ближник: рывок к цели → ~200 мс] → кольцо над целью → клик (perfect/good/miss) → урон **этой** цели (`applyStrike([idx], qteMult)`) → **микро-пауза 100 мс** (глаз переносится на новую цель) → следующая цель → … У каждого удара свой множитель. Слоу-мо одно на весь стрим (`holdSlowMo`: onResolve оверлея НЕ разгоняет мир, `qteSlowMo.end()` зовёт цикл после последнего звена). Мёртвая/исчезнувшая цель безопасно пропускается (чек до и после `await`). Каждый QTE-оверлей ремоунтится по `key={qte.id}`; «протухший» `onDone` догорающего вердикта не гасит следующее кольцо (гвард по id). Победа/сброс карты — один раз после всей серии (`finishCardPlay`).
- **Пинбол-рывок ближника** (`dmgType: 'melee'` в стриме, напр. Удар мечом / Берсерк): спрайт героя физически дэшится к текущей цели серии. База героя фиксируется до первого transform (`heroBaseRect`), все векторы считаются от неё — CSS-transition интерполирует от текущей позиции, и герой летит **Base → T1 → T2 → … → Base напрямую**, без телепорта домой между ударами (`dashTo` + `await qteSlowMo.delay(200)` перед монтированием кольца). К первой цели герой прыгает обычным лип-прыжком при розыгрыше (его время покрывает `impactDelay`), домой возвращается после последнего звена. Дальники (ranged/magic) стоят на месте — у них стрим без рывков.
- Одиночная цель (или жива 1) — кольцо над спрайтом цели, как раньше.

**Скорость сужения** (`calculateQteDuration`):
```
duration = max(350, 900 − штраф_редкости − штраф_комбо)   // мс
штраф_редкости: RARE −100, EPIC −250, LEGENDARY −400
штраф_комбо:    2-е звено −100, 3-е+ −200
```
Хард-кап 350 мс — предел человеческой реакции.

**Ввод:** на время QTE весь экран — кнопка (полноэкранный клик-катчер); важен только тайминг, целиться не нужно.

**Презентация (v2, «Perfect Strike»):**
- **Изинг кольца** — ease-in-quad: первую половину времени кольцо еле ползёт (читаешь сетап), в конце ныряет в мишень с ускорением. Судья тайминга — во времени, изинг чисто визуальный.
- **Видимые зоны тайминга** — пояса GOOD (тусклый) и PERFECT (яркий) вокруг мишени, пересчитаны через ту же кривую изинга: игрок видит геометрию окна (референс: osu!, active reload из Gears).
- **Виньетка-фокус** — радиальное затемнение вокруг QTE, бой гаснет (Sekiro-style), плавный fade in/out.
- **Карта-контекст** — крупная иконка (72px) + имя разыгрываемой карты над кольцом: понятно, что усиливаешь.
- **«Заряд»** — при входе в good-окно кольцо вспыхивает янтарным + тихий тик (`onArm`): сигнал «жми сейчас».
- **Вердикт** — ударная волна + 8 искр (perfect) + крупный текст (42px perfect / 32px good-miss).

**Bullet-time:** пока кольцо активно, весь мир плавно замедляется до ×0.35: прыжок героя, снаряды, idle-анимации, попапы. Изинги рампы: вход ~260 мс ease-in-cubic (сперва еле заметно, в конце «провал»), выход ~300 мс ease-out-cubic (резкий разгон, мягкий доезд). **Кольцо и тайминг-судья — в реальном времени** (окна ±60/±150 мс — настоящие миллисекунды). Реализация — `src/qteTimeScale.js` (`qteSlowMo`): единый rAF-цикл выставляет `playbackRate` всем Web Animations документа (кроме узла `[data-qte-overlay]`) и ведёт «игровое» время для задержки импакта.

**Результат** (множитель к итоговому урону карты, см. порядок в 3.1):
| Вердикт | Окно | Множитель | Звук |
|---|---|---|---|
| PERFECT! | ±60 мс от совпадения колец | ×1.35 | `hit_heavy` |
| GOOD | ±150 мс | ×1.15 | `click` |
| MISS | раньше / позже / игнор (авто-мисс через `duration+150` мс) | ×1.0 | — |

**Техника и гварды (не ломать!):**
- Урон применяется через `Promise.all([impactDelay, qtePromise])`; импакт — 300 мс **игрового** времени (`qteSlowMo.delay`), под слоу-мо тянется синхронно с замедленным визуалом.
- Кольцо анимируется rAF-циклом, transform пишется напрямую в DOM через ref (ноль setState на кадр); тайминг судится тем же `performance.now()` — **реальным**, не игровым.
- **Запрещено** растягивать длительности транзишенов/сетТаймаутов вручную под `qte.duration` — рассинхронизирует судью тайминга (был инцидент). Единственная точка замедления мира — `qteTimeScale.js`.
- Авто-завершение хода и кнопка «ЗАВЕРШИТЬ» заблокированы, пока `qte != null` (урон последней карты ещё не применён).
- `resetGame` резолвит висящий промис нейтрально (`resolve(1.0)`) и вызывает `qteSlowMo.end()`, иначе розыгрыш зависнет / мир останется замедленным.

## 5. Вторичные эффекты (дебаффы)

Сила отвязана от статов: `v = SECONDARY_BASE_POWER(=14) × 2^(level−1) × combo`.

| Эффект | Ключ | Формула | Длительность (ходов врага) |
|---|---|---|---|
| 💫 Оглушение | `stun` | шанс `v×2%` (кап 95%); враг пропускает ход | 1 |
| 🛡️ Пробитие брони | `vuln` | цель получает `+v×1%` урона (кап +80%) | 2 |
| 🩸 Кровотечение | `bleed` | `v×0.5` урона/ход (тик в начале фазы врага, может добивать) | 3 |
| 🌀 Ослепление | `blind` | шанс промаха врага `v×2%` (кап 95%) | 2 |
| ⬇️ Ослабление | `weaken` | `−v×1%` к атаке врага (кап −80%) + мгновенно `v×0.5` HP | 2 |
| 🎯 Метка | `mark` | след. удар — гарант. крит ×2 и ещё `×(1+v×1%)` | до первого удара |

- Стак — через `max` (`applyStatusToEnemy`), **не суммируется**.
- Длительности тикают в `decrementStatuses` в конце фазы врагов; `mark` не тикает (снимается первым ударом).
- `bleed` обрабатывается **в начале** фазы врага, присуждает XP/лут через стандартный путь смерти (босс от кровотечения тоже роняет легендарку).
- UI: иконки статусов с числом ходов над спрайтом врага + тултип (`describeStatus`).

## 6. Карта сектора, враги

### 6.1. Карта сектора

- Генерируется заново на каждый сектор (`generateMap`): 6 слоёв (stage 0–5), ветвящиеся связи. Слой 0 — база (пройдена сразу), слой 5 — босс.
- **Плотность:** слой 1 — фиксированно 2 узла (у базы максимум 3 исходящих ребра, при 4+ узлах появлялись бы сироты без входа; и каждый узел слоя 1 — своя цветная «линия метро», 2 узла = 2 цвета). Слои 2–4 — случайно 2–6 узлов, до 3 исходящих рёбер и до 3 ветвлений на узел (широкий разброс, иначе детерминированный граф связей повторяется из раза в раз).
- **Рендер:** карта — absolute-оверлей `MapOverlay` (`absolute left-0 right-0 bottom-0 top-[360px] z-[500]`) нижней зоны боевого экрана: арена с героями/врагами (355px + 5px отступ) остаётся видимой сверху, оверлей накрывает панель слотов героев и полосу лута до низа контейнера по всей ширине блока арены, под картой `backdrop-blur-xl` (`bg-slate-950/40`). **Ноль layout shift** — подлежащий DOM не размонтируется и не двигается. Боковые колонки (Энергия+Колода, ЗАВЕРШИТЬ+Сброс), слоты карт героев и полоса лута на фазе карты гаснут через `opacity-0 pointer-events-none` (рефы `deckRef`/`discardRef`/`inventoryRef` живы для анимаций). Легенды узлов на панели нет — типы читаются по иконкам.
- **Появление:** панель с `backdrop-blur` держит `opacity: 1` постоянно (по спецификации элемент с `opacity < 1` становится "backdrop root" и обрезает выборку `backdrop-filter` только своим содержимым — блюр слепнет, даже если увеличивать его силу). Полупрозрачная панель с блюром возникает мгновенно, а проявляется (fade-in 0.25s, `.map-content-in`) только содержимое: линии, узлы, заголовки — никакого «тёмного прямоугольника перед картой». Выбор узла → `turnState` уходит из `'map'` → оверлей исчезает.
- Типы промежуточных узлов: 🗡️ лёгкий (`combat_easy`), ⚔️ средний (`combat_medium`), ☠️ сложный (`combat_hard`), ✨ событие (`event`).
- Перейти можно только в соединённый узел (доступные пульсируют, пройденные тускнеют).

### 6.2. Ростер врагов

Роли: `melee` (прыгает к цели, бьёт одного), `ranged` (не прыгает, снаряд), `aoe` (бьёт всех героев). Код: `ENEMY_TYPES`, `spawnEnemies`.

| Враг | Множ. урона | Роль | VFX | Где спавнится |
|---|---|---|---|---|
| Слизень 🟢 | 0.65 | melee | enemy | лёгкий, средний |
| Гоблин 👺 | 0.80 | melee | enemy | лёгкий |
| Зомби 🧟 | 0.85 | melee | enemy | средний, сложный |
| Волк 🐺 | 1.00 | melee | enemy | лёгкий |
| Бандит 🦹 | 1.10 | melee | enemy | лёгкий |
| Стрелок 🏹 | 1.10 | ranged | arrow | средний |
| Орк 🪓 | 1.40 | melee | smash | сложный |
| Тёмный маг 🧙 | 1.45 | ranged | dark_void | сложный |

**Состав боёв:** лёгкий — 1–2 из {Слизень, Гоблин, Волк, Бандит}; средний — 2 из {Зомби, Стрелок, Слизень}; сложный — {Орк, Тёмный маг, Зомби} все три; босс — один Глаз.

### 6.3. Масштабирование сложности

Сложность задаётся **сектором**, а не уровнем игрока:
```
s    = stage(0..5) + (sector − 1) × 6
mult = 1.55^(sector − 1)
HP врага = round((HP-база + s × прирост) × mult × ENEMY_POWER_MULT)
XP врага = round(XP-база × mult)
```
Глобальный нерф: **`ENEMY_POWER_MULT = 0.5`** — HP и урон врагов ×0.5.
Базовые HP/прирост/XP (до масштаба):
- Слизень 35/+10/50 (лёгкий) · 45/+11/65 (средний); Гоблин 45/+12/55; Волк 40/+11/50; Бандит 48/+13/60.
- Зомби 70/+18/90 (средний) · 95/+26/130 (сложный); Стрелок 55/+14/85; Орк 100/+28/150; Тёмный маг 60/+18/140.
- **Босс Глаз:** 280/+65/400, понерфлен −30% HP и −25% к атаке (`dmgMult ×0.75`).

### 6.4. Ход врага

- Каждый живой враг по очереди атакует **случайного** живого героя (босс-`aoe` — всех сразу).
- База урона: `(random(0..7) + 8 + текущий_этаж × 3) × ENEMY_POWER_MULT`, затем `× dmgMult × (1 − ослабление)`, снижается бронёй: `получено = max(1, урон − armor)`.
- Дебаффы учитываются: stun — пропуск хода, blind — шанс промаха.
- При входе в бой случайный враг выкрикивает фразу-оскорбление (3.5 сек).

## 7. Боевая машина состояний (`turnState`)

`map → dealing → player → enemy → map | gameover`

Состояний `victory_wait`/`victory` **больше нет** (flow state): HP последнего врага достиг 0 → `triggerVictoryTransition` — обычный узел → пауза 700ms (доигрывает анимация смерти; розыгрыш карт и «Завершить» заблокированы через `victoryPauseRef`) → `enterMapPhase`: поле боя очищается полностью (трупы врагов, комбо-руна, подсветки, VFX, реплики) и `MapOverlay` проявляется поверх пустой арены. Босс (слой 5) → сразу заставка нового сектора (`SectorSplashScreen`), отдельного экрана «СЕКТОР ЗАЧИЩЕН» нет. Открытый level-up откладывает переход (`pendingTransitionRef` → `runPendingTransition` → `enterMapPhase`).

> Поверх FSM живут оверлеи вне машины состояний: **Таверна-Хаб** (`showTavern`, см. [`meta.md`](./meta.md)) и **QTE** (`qte`, удерживает фазу `player`).

- **map** — карта сектора, выбор узла.
- **dealing** — раздача карт каждому живому герою из общей очереди (своя карта или мод-карта; если в резерве нет карты героя — бесплатная базовая атака). Каждые 3 раздачи (`dealCounterRef`) сброс перемешивается в резерв. Мана восстанавливается до `maxMana`. Броня от мод-карт обнуляется.
- **player** — клик по карте героя → `playCard`. Карта разыгрывается мгновенно, анимации параллельны, ввод не блокируется (синхронные гварды `actingRef`/`manaRef`). Завершение хода: вручную («ЗАВЕРШИТЬ») или авто, когда никто не может сделать легальный ход. Неиспользованный `chainAttackBonus` сгорает.
- **enemy** — последовательная атака живых врагов: тик кровотечения → ход атакующего (stun/blind/weaken) → урон героям через `applyIncomingDamage`.
- **gameover** — экран смерти (см. [`meta.md`](./meta.md)).

Мана: `MAX_MANA = 3`, стартовая и максимальная; +1 только из события «Осколок Эфира». Восстанавливается до максимума при каждой раздаче.
