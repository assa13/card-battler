# Мета и прогрессия

Единый источник истины по мета-слою: предметы/лут/крафт, опыт и уровни, события, смерть и огоньки души, Таверна-Хаб, экран подготовки.
Боевое ядро — в [`core.md`](./core.md), графика/звук — в [`vfx.md`](./vfx.md).

---

## 1. Предметы (лут, инвентарь, экипировка, крафт)

### 1.1. Редкости

| Редкость | Название | Цвет | Тинт |
|---|---|---|---|
| COMMON | Обычная | серый | нет |
| RARE | Редкая | синий `#0EA5E9` | синий |
| EPIC | Эпическая | фиолетовый `#a855f7` | фиолетовый |
| LEGENDARY | Легендарная | золотой `#f59e0b` | золотой |

### 1.2. Бонусы предмета

Пул бонусов — `ITEM_STAT_TYPES = ['atk', 'matk', 'crit', 'hp']`:
- **`atk`** — +% к физ. урону (melee/ranged); **`matk`** — +% к маг. урону; **`crit`** — +% к шансу крита; **`hp`** — плоское здоровье.

Генерация (`rollItemStatBundle`):
- **Число бонусов** по редкости (`ITEM_BONUS_COUNTS`): COMMON 1, RARE 1–2, EPIC 2–3, LEGENDARY 2–4.
- **Величина** (`ITEM_STAT_RANGES`): COMMON 4–7, RARE 9–14, EPIC 17–25, LEGENDARY 30–45. Первый бонус полный, последующие ×0.32–0.50.
- `hp` дополнительно ×`ITEM_HP_MULT = 2.5` (мин. 4); `crit` ×`ITEM_CRIT_MULT = 0.5`.

Бонусы применяются через `getEffectivePlayer` **только пока предмет надет**. При снятии `syncPlayerMaxHp` обрезает HP под новый максимум. Привязка к характеристикам (`str/dex/int`) полностью удалена.

### 1.3. Шаблоны и тинт

Базовый ассортимент — иконки `item_NN.webp` с фиксированной базовой редкостью («пирамида»: больше COMMON). Шаблон низкой редкости можно «поднять» цветным тинт-оверлеем (`RARITY_TINT`) + префикс «Редкий/Эпический/Легендарный». Подбор — `pickTemplateForRarity` (родные шаблоны в 3 раза чаще). Поле `focus` — легаси.

### 1.4. Выпадение лута (прогрессивная редкость)

- Убийство обычного врага: шанс `LOOT_DROP_CHANCE = 0.65`.
- Редкость от **глубины захода** (`rollItemRarity`): `depth = (sector−1)×6 + max(0, stage−1)`, `t = min(1, depth/22)`; веса COMMON `78 → 40`, RARE `16 → 30`, EPIC `5 → 20`, LEGENDARY `1 → 10`.
- **Босс всегда** роняет легендарку — без ролла (в т.ч. при добивании кровотечением).
- Предмет летит в инвентарь с анимацией (`FlyingItem` через `fxRef`).

### 1.5. Инвентарь

- `INVENTORY_SIZE = 9` ячеек.
- Переполнение → **первый предмет сгорает в XP** (`ITEM_BURN_XP`: COMMON 4 / RARE 8 / EPIC 16 / LEGENDARY 30), остальные сдвигаются (`addItemToInventory`).

### 1.6. Экипировка

- Под карточкой каждого живого бойца — слот на **1 предмет**. Надевание — drag-and-drop из инвентаря (свап, если занят). Снятие — клик (в первую свободную ячейку).
- Тултип с бонусами при наведении (`+%` / `+HP`, зелёным).
- При гибели отряда **надетая экипировка сохраняется** на следующий забег; ненадетый инвентарь продаётся в мету (раздел 4).

### 1.7. Крафт

- **3 предмета одной редкости → 1 предмет следующей** (`getNextRarity` + `generateItemOfRarity`). Легендарные не улучшаются.
- Кнопка «Слияние» в UI крафта относится к **предметам**, не к картам (слияния карт в игре нет).

## 2. Прогрессия отряда (опыт и уровни)

- Враги дают XP (общий для отряда). Порог: старт **120** (`XP_BASE_THRESHOLD`), далее **+100** за уровень (`XP_THRESHOLD_STEP`): 120, 220, 320… Излишек переносится; за один прирост можно взять несколько уровней (`gainXp` считает все).
- **Нерф темпа (два слоя):** (1) весь входящий XP **×0.25** (единая точка приёма `gainXp`, минимум 1) — режет и убийства (вкл. кровотечение), и сжигание предметов; (2) пороги уровней ×2 (было 60+50×N). Суммарно прокачка ×8 медленнее исходной.
- Мана: `MAX_MANA = 3`, не растёт с уровнем (+1 только «Осколок Эфира»).
- При повышении уровня:
  - HP-фундамент каждого героя растёт на `HP_PER_LEVEL` (Воин 8 / Разбойник 6 / Маг 4).
  - Экран «УРОВЕНЬ ПОВЫШЕН!» — выбор **1 из 3** наград (`buildLevelUpOptions`): новая карта (в свободный слот героя / мод-карта глобально) или апгрейд имеющейся (+1 уровень, ×2 урона). Только живым героям; занятый пул героя даёт только апгрейды. Очередь уровней (`levelUpQueue`) — по одному выбору на уровень.

## 3. События (узел ✨)

Случайный нарратив (6 заготовок) + **выбор 1 из 3** бонусов (`POWERUPS`, `handleEventChoice`):

| Бонус | Иконка | Эффект |
|---|---|---|
| Осколок Эфира | 🔵 | Максимальная мана +1 |
| Эликсир Мощи | 💪 | Атака и маг. атака каждого бойца +5% |
| Семя Жизни | ❤️ | Максимальное HP всех героев +50% (через `baseMaxHp`) |
| Древний Фолиант | 📜 | Выбор 1 из 3 карт (как на level-up) |

## 4. Смерть и мета-прогрессия

### 4.1. Огоньки души (`soulEmbers`)

Мета-валюта, **сохраняется между забегами**. Накапливается из проданного при смерти ненадетого инвентаря:
- Каждый предмет даёт очки хлама `JUNK_SOUL_POINTS`: COMMON 1 / RARE 4 / EPIC 10 / LEGENDARY 25.
- Очки копятся в глобальную шкалу (`soulProgress`); за каждые `EMBER_JUNK_THRESHOLD = 11` очков — **+1 огонёк**; остаток переносится.

### 4.2. Экран смерти (`DeathScreen`)

Показывает ненадетый инвентарь (надетое остаётся на героях), анимирует продажу хлама в очки и выплату огоньков. Завершение (`handleDeathDone`) → зачисление огоньков → `resetGame(fromDeath)` → возврат в **Таверну-Хаб**.

### 4.3. Что сбрасывается / сохраняется при смерти

- **Сбрасывается:** уровень отряда, XP (порог снова 120), мана (3), сектор → 1, модификаторы от усилений, броня, **run-карты из level-up** (колода пересобирается: стартовые + перманентные + 2 мод-карты).
- **Сохраняется:** надетая экипировка (бонусы пересчитываются при респавне), огоньки души и прогресс шкалы, **перманентные карты** (`permanentlyUnlockedCards`, localStorage).
- **`fullReset`** — полный сброс, включая экипировку и валюту; в обычном UI не вызывается.

### 4.4. Таксономия карт героя (`src/heroCardInventory.js`)

| Тип | Источник | Живёт | Хранение |
|---|---|---|---|
| Стартовая | хардкод `HERO_ABILITIES[id].basic` | всегда | не хранится |
| Перманентная | покупка за огоньки (prep), награды событий/диалогов (`UNLOCK_HERO_CARD`) | переживает смерть, открыта с начала рана | `permanentlyUnlockedCards` → localStorage |
| Run-карта | награда level-up в бою | до смерти отряда | только drawPile/discard |

Лимит перманентных слотов на героя — `MAX_PERMANENT_CARDS` (по умолчанию 2; пул героя `CARD_POOL_SIZE=4`: 1 стартовая + ≤2 перманентных + ≥1 под run-карты). Разблокировка сверх лимита молча игнорируется (`hasFreePermanentSlot`). Сжигание перманентной карты на prep-экране освобождает слот навсегда (`removeUnlockedHeroCard`).

### 4.5. Сюжетные смерти (счётчик `deathCountRef`)

- **1-я смерть** → `firstDeathStoryPending`: вход в таверну встречает линейной историей (триггер `FIRST_DEATH`), по завершении — бесплатная перманентная карта случайному герою со свободным слотом (`grantFirstDeathFreeCards`).
- **2-я и последующие** (пока Незнакомец не впущен) → `strangerStoryPending`: ветвящийся скрипт `STRANGER_SECOND_DEATH_SCRIPT` (`src/dialogue/scripts/strangerSecondDeath.js`) играет на экране встречи через проп `entryScript` таверны. Наёмник Незнакомец предлагает впустить его:
  - **Впустить** → команда `STRANGER_JOIN_TAVERN` → `strangerInTavern = true` (localStorage `idler_strangerInTavern`): атлас stranger.png (4×4 idle) перманентно заменяет посетителя `visitor_cloaked_center` за центральным столом.
  - **Прогнать** → «Я всё равно приду» — событие повторится после следующей смерти.
- **Мета-прогресс `maxSectorReached`** (localStorage `idler_maxSectorReached`) — лучший достигнутый сектор, смертью не откатывается. Условие найма Незнакомца — «Дойдите до пыточных» (сектор 2). Найм: `STRANGER_HIRE_GOLD_COST` (250 🪙), заменяет одного из трёх героев (`hireStranger` → `strangerHiredAs` в localStorage). Заглушка в карусели показывает 🪙 цену и кнопки «Заменить …».

### 4.6. Глобальный кошелёк и экономика инвентаря

- **`WalletHUD`** (`App.jsx`, z 9650) — правый верхний угол на всех экранах после прелоадера: `🪙` золото + `🔥` огоньки души. Дублирующие счётчики на экранах убраны.
- **Золото 🪙** (`gold`, localStorage в `idler_heroInventoryMeta`): разблокировка карт коллекции (`getCardUnlockGoldCost` по редкости), апгрейд карт, найм Незнакомца. Источники — диалоги (`GIVE_GOLD`), посетители таверны.
- **Огоньки души 🔥** (`soulEmbers`): prep-покупки карт, разблокировка **слотов лоадаута** героя (`getLoadoutSlotUnlockPrice` — та же лестница `[1,1,3,6,11,22]`, первый слот бесплатный). В карты коллекции больше не тратятся.
- **Получение карты в мете** — `CardRevealOverlay` (крутящаяся/переворачивающаяся анимация): первая смерть, диалоги, разблокировка за золото, level-up, prep-покупка. Устаревший `SquadSlotsPopup` снят.

## 5. Таверна-Хаб (`TavernHubScreen.jsx`)

Стартовый мета-экран и точка возврата после смерти (`showTavern` в `App`; перекрывает всё, z-9000).

- **Сцена:** `ScreenStage` с `aspectRatio = TAVERN_STAGE_RATIO` (1024/529 — пропорция `bg_base.webp`), `fill = 0.8203125`. Сущности декларативно из `TAVERN_ENTITIES` (`TavernSceneConfig.js`): типы `BG / NPC / PROP / HERO_ACTIVE / VISITOR / PORTAL`, глубина — индивидуальный `zIndex`. Координаты — проценты логического холста 3200×1800 (см. [`screen-scale.md`](./screen-scale.md)).
- **Ночная фаза:** стук у двери → `NightEncounterScreen` (z 9500) → ветвящийся скрипт; награды через `DIALOGUE_COMMAND` (`UNLOCK_HERO_CARD { heroId, cardId }`, `GIVE_GOLD`).
- **Интерактив:** тройка активных героев у стойки (`HERO_ACTIVE`, спрайты — атласы героев с idle-анимацией), бармен (`NPC`), невидимая клик-зона двери «В поход» (`PORTAL`, справа). Hover — обводка по силуэту ([`vfx.md`](./vfx.md), раздел 7).
- **Маршруты:** клик по герою → `onOpenPrepScreen` (выделенный проп, не generic-диспетчер) → экран подготовки; дверь → `onAction: OPEN_MAP` → карта сектора.
- **Заготовлено, не активно:** `OPEN_BARTENDER_DIALOG`, `INSPECT_RECRUIT` (экранов нет), `recruitsPool` (в `App` не передаётся), блокировки по мин. сектору (`minSectorRequired` → бейдж `🔒 Сектор N+`, grayscale).
- **Вход в игру:** прелоадер → Таверна → дверь → карта. После смерти: экран смерти → Таверна.

## 6. Экран подготовки (Prep Screen)

Открывается из Таверны кликом по герою у стойки. Случайный фон + готичная фраза (`GOTHIC_PHRASES`), баланс огоньков, плашки героев с пулом карт (`SquadSlotsBoard`). Действия:

- **Покупка стартовой карты** (`buyPrepCard`) — система автоматически и случайно выбирает карту из доступного пула героя (или мод-карту); цены `PREP_SLOT_PRICES = [1, 1, 3, 6, 11, 22]`. Лимит — **2 карты за забег** (`PREP_MAX_BUYS`, в UI не афишируется).
- **Сжигание карты** (`burnPrepCard`) — ровно `PREP_BURN_COST = 1` огонёк; стартовые карты сжечь нельзя.
- При покупке — анимация получения (`CardRevealOverlay`, ~3с): шейдер-фон, карта рубашкой, увеличение с дрожанием, переворот; «Нажмите любую кнопку».
- Глобальный шейдер/блюр под экраном отключаются ради производительности.
