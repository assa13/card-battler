# Pixel Grid — пробный общий фильтр

Доступен в тестовой ветке `test/dungeon-sector-map`, запуск на `http://127.0.0.1:5185/`.
Панель находится справа снизу и сворачивается нажатием на заголовок.

- **Grid Size** — 1, 2, 3 или 4 физических пикселя экрана, с учётом DPR.
- **Grid Strength** — смешивание исходного кадра с обработанным, 0–100%.
- **Grid Offset X/Y** — положение общей сетки, в физических пикселях.
- **Сбросить** — 2 px, 25%, смещение 0/0. Настройки сохраняются локально в браузере.

При 100% каждый квадрат сетки получает цвет одного пикселя исходного кадра.
При промежуточной силе исходное изображение подмешивается для сохранения мелких деталей;
это намеренно мягкий режим, без строгой однородности цвета внутри квадрата.
Размер 1 px и сила 0% полностью снимают фильтр.

## Устройство

Это гибрид для просмотра без переноса интерфейса в Canvas: WebGL 1 создаёт карту
смещений, а SVG-фильтр браузера применяет её к собранному содержимому `#root`.
HTML-интерфейс, CSS-фоны и игровые Canvas получают одну сетку с началом в левом
верхнем углу экрана. Панель вынесена за пределы фильтра.

Карта рассчитывается только при изменении размера сетки, смещения, окна или DPR.
Изменение силы обновляет только коэффициенты смешивания. Покадрового захвата DOM,
`readPixels`, загрузки кадра в WebGL и дополнительного постоянного цикла анимации нет.
Обработка кадра остаётся работой браузерного композитора; это не перенос всей игры
в единый WebGL-рендерер. Итоговые затраты зависят от браузера и размера окна.

RGBA8-карта использует диапазон смещения 8 px и sRGB без дизеринга.
Nearest-сэмплирование композитора Chromium сохраняет выбранный пиксель несмотря
на округление каналов карты. Крайние неполные клетки ограничены границами кадра.
При ошибке WebGL эффект отключается, причина выводится в панели.

Подключение — один компонент `PixelGridEffect` в `src/main.jsx`.
Удаление его импорта и JSX полностью убирает эксперимент.

Проверка математики: `node --test src/rendering/pixelGrid.test.js`.
Для сравнения глазами: сила 0% → 100%, размер 4 px, затем «Сбросить».
