# КАК КАКАТЬ

## Релиз

Собранный проект лежит в папке `./dist`.

## Сборка новой версии

```bash
npm run build
```

Запускает сборку — релиз попадает в `./dist`.

## Запуск разработки

```bash
npm run dev
```

Поднимает dev-сервер с hot-reload.

## Git-коммиты

После каждого крупного изменения попросить LLM:

> Сделай гит коммит на англ, осмысленное название с описанием последних изменений
